# 노정원 포트폴리오

수원정보과학고등학교 재학 중인 노정원의 개인 포트폴리오 웹사이트입니다.
보안·네트워크·백엔드를 중심으로 진행한 프로젝트와 기술 역량을 정리했습니다.

🔗 **웹사이트**: https://njw.kro.kr

## 구성
- **소개 / 활동 / 기술 역량 / 계획** 섹션
- **프로젝트 갤러리** — GetAPI, njwsec.shop, 홈랩 보안 로그 분석, MSWCS 등

## 기술
- HTML5 · CSS3 · JavaScript (ES6+)
- Canvas 기반 인터랙션, 반응형 레이아웃
- 블로그 연동 (Cloudflare Workers)

## 주요 관심 분야
- **네트워크** — OSI 7계층, TCP/IP, 서브네팅
- **정보보안** — 웹 취약점, 암호학, IPS 로그 분석
- **백엔드** — REST API, 인증, 성능 최적화
